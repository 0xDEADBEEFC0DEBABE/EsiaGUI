# Test fonts

The FreeType + HarfBuzz text tests (`tests/text/test_ft_text.cpp`) and their golden images use these fonts; they
came with Dear ImGui's `misc/fonts` in WGT.

* `DroidSans.ttf`: Droid Sans by Steve Matteson, Apache License 2.0.
* `Karla-Regular.ttf`: Karla by Jonathan Pinhorn, SIL Open Font License 1.1 (1000 units per em: the tests use it as
  the fallback font).
